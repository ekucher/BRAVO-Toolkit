# Engineering Workflow

- Inspect before editing.
- Search for related implementation and usages before changing public behavior.
- Prefer repository-native patterns over new abstractions.
- For non-trivial changes, establish a short implementation plan internally before editing.
- Resolve discoverable facts from the repository rather than asking the user.
- Keep modifications tightly scoped to the requested outcome.
- Prefer reversible operations.
- Review the final diff before declaring the task complete.
