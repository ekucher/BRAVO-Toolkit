# Change Safety

- Assume uncommitted changes may belong to the user.
- Preserve unrelated modifications in files you edit.
- Do not delete or rewrite code merely because it appears unused without verifying its callers.
- Do not manually edit generated artifacts when a source/template/generator exists.
- Do not perform broad formatting as part of a functional fix.
- Do not silently alter configuration defaults.
- Do not add compatibility-breaking behavior unless explicitly required.
- Do not use destructive commands when a non-destructive alternative exists.
